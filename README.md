# ADS506 Module 5: Australian Wine Forecasting Explorer

## Project Description
An interactive Shiny application for exploring monthly sales across six Australian wine varietals from 1980 to 1994.

## Features
- Explore historical sales patterns across wine varietals.
- Generate forecasts using TSLM, ETS, and ARIMA.
- Customize training periods and forecast horizons.
- Compare model accuracy using RMSE, MAE, and MAPE.
- Visualize forecasts with prediction intervals.

## Dataset
Australian wine sales dataset (`AustralianWines.csv`).

## How to Run
1. Clone or download this repository.
2. Open `ADS506_Module5.Rproj` in RStudio, or set the project directory.
3. Install the required packages if needed.
4. Run `app.R` to launch the Shiny application.
